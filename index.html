06 — Method

How I work
under pressure.

Six principles that govern how I touch a production codebase.

01

Understand architecture before code

Analyse domain logic and UI structure first, so changes don't create silent side effects in production.

02

Root-cause performance tuning

Diagnose memory leaks, orphaned subscriptions and DOM re-renders with profilers rather than guessing.

03

Protect production stability

Keep battle-tested flows intact while introducing modular, reversible enhancements.

04

Predictable state flow

Deterministic NGXS and RxJS streams that stay readable, centralised and testable.

05

Automate journey verification

E2E coverage on critical paths so regressions surface before production environments.

06

Balanced execution

Business delivery speed held together with maintainable component design and clean standards.
